# Legacy problem bank snapshot

This directory is an immutable import of the previous Adaptive Math Learning problem bank. The source path in `manifest.json` is provenance only; runtime code reads this local snapshot and does not depend on the previous checkout.

The original rich problem schema is retained, including answer types, 3-5 answer choices, manual-review rubrics, curriculum and taxonomy metadata, explanations, and asset references. Imported content is not relabeled as part of the current 50-problem human-review batch.
